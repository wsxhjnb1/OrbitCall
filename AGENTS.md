# OrbitCall project contract

All numerical experiments, model inference, correctness tests, calibration,
timing and statistical analysis run on the authorized DGX Spark GB10. Windows
is used for editing, public asset downloads, transfer, publication and resume
compilation. Do not run model experiments on another host.

Use only public, revision-pinned model checkpoints and public BFCL inputs.
Do not copy private research source, methods, checkpoints or logs into this
repository. Ground-truth answers must be isolated from candidate generation
and scoring; the offline evaluator reads them only after predictions freeze.

Preserve failures and all raw measurements. Do not change the scientific
protocol after observing confirmatory results. Infrastructure corrections
require a dated amendment and a new run ID. Never overwrite completed runs.

No fabricated speed, accuracy, novelty, publication or upstream merge claims.
Separate score-stage speed, complete pipeline cost and task quality. Credit
prior work and document the restricted finite serialization family. Model
weights, answers, private filesystem paths and credentials are not published.

Do not interrupt unrelated jobs. Confirm whole-host availability before GPU
work; terminate only project-owned process groups. Children inherit the
parent's model and reasoning effort. Publish to the user's personal GitHub
only after implementation, experiments and evidence checks are complete.
